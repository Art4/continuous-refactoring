# Laravel Pint

A recognized Tool for the Role Code Style in the PHP Pack: counted when it is there, never proposed. A target that runs Pint has the Role filled, so PHP CS Fixer is out. Pint is built on PHP CS Fixer and reads `pint.json`.

### `pint`

- **Purpose:** automated code style, so later Rector output lands styled.
- **Fulfilment check:** `laravel/pint` is installed as a dev dependency, and `vendor/bin/pint --test` runs locally with zero reported diffs. A committed `pint.json` is not required; Pint has a default preset.
