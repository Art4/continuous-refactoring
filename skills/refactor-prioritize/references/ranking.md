# Ranking Reference

Five factors for prioritising proposals.

| Factor | Question |
|---|---|
| **Heat** | Is it in a hot spot (frequently changing area)? |
| **Leverage** | How much future change does deepening this unlock? |
| **Tooling pressure** | Is fulfilled tooling actively flagging it? |
| **Risk** | How hard to reverse / how wide the blast radius? Prefer reversible early. |
| **Skip streak** | How many consecutive passes proposed without choosing? Longer → increasingly favored, but still one factor among five. |

Present as short ordered list of **Names** only. Rationale saved for the recommendation.
