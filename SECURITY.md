# Security Policy

## Supported versions

This project ships as a rolling `main` branch — there is no version matrix. Security fixes land
on `main`.

## Reporting a vulnerability

Please **do not** open a public GitHub issue for a security vulnerability. Instead, use GitHub's
private reporting: on this repository, go to the **Security** tab → **Report a vulnerability**
(private vulnerability reporting).

If that's not available to you, reach out via [weigandtlabs.de](https://weigandtlabs.de) instead.

We'll acknowledge reports as quickly as we can and keep you updated as we work on a fix.
