# Issue tracker

Tickets are local markdown files under `tickets/`.

## Refactoring operations

- **Search:** search `tickets/` for the words, open and closed together; open ones have `Status: open`.
- **Done:** a ticket is done when its file says `Status: done`.
- **Merge requests:** none — the prepared branch is handed to the human.
- **Tooling Pack:** `docs/agents/tooling-pack/`
