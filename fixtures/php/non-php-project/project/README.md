# non-php-project fixture

A static HTML/CSS/JS site — no `composer.json`, no `*.php` file anywhere. Stands in for a
target like `continuous-refactoring.de`: `is-php-project` (`skills/refactor-scan/references/tooling-tree.md`)
stays unfulfilled here, which keeps `composer`/`php-minimal-version` and everything beneath them
out of `next`/`roadmap` — see ADR-0022.
