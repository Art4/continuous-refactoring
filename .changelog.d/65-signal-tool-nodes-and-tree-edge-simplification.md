Neither carries a `resolved` edge into `structural-scan`: adopting them enriches candidate selection, they never gate structural work. Node docs gain an optional `Signal` field (mirroring the existing `Housekeeping` field) naming which factor a node's output feeds; `CONTEXT.md`'s `Signal` entry now covers both this node-level usage and the existing candidate-issue-field one. Three PHP-tree edges simplified: `test-runner-if-missing` drops its direct `php-structural-scan` resolved edge (no replacement — `ci-runner` already gates `structural-scan` independently); `php-cs-fixer` drops its own direct resolved edge in favor of a new `recommended` edge into `rector-php-set`, which still forces it to be decided first; the PHPStan level chain's resolved-leaf moves from level 10 to level 5 (its first structural fork point), leaving levels 6–10 ordinary, non-gating, still-proposable nodes.
