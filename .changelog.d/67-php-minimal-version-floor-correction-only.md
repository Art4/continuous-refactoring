`php-minimal-version` no longer proposes raising `composer.json`'s declared PHP floor beyond what the codebase's own code already requires — only a Floor correction (bringing the declared floor in line with syntax `rector-php-set` has already landed) is ever auto-proposed now, never a Floor raise (committing the application to a newer PHP than its code currently needs, a real breaking change). `CONTEXT.md` gains `Floor correction`, `Floor raise`, and `Breaking change` glossary entries.
