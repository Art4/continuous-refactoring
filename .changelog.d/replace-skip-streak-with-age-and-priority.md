`Skip streak` is gone — replaced by two signals `refactor-prioritize`'s Rank mode now reads directly off each proposal's own pre-filed issue: its age (how long it's sat open, one factor among five, same as before) and a human-settable `refactor:priority` label (a hard override — narrows the candidate pool to only priority-labeled proposals when any exist). Local Markdown issue trackers gain a `Filed: YYYY-MM-DD` line so age is readable there too; native trackers already expose a creation date.
