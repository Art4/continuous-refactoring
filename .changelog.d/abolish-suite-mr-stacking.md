Suite merge requests no longer stack — every branch this suite opens (a candidate's own, a dedicated bookkeeping branch, `loop-config`'s) now always branches directly off the default branch, unconditionally. Reverses ADR-0015 after two real incidents where a stacked PR got silently auto-closed by the forge when its base branch was deleted on merge; the concurrent-write conflict the old rule protected against never once materialized in practice. `docs/playbooks/reviewer-loop.md` also gains a standing rule: check for a PR based on a branch before deleting it, regardless of whether the suite itself stacks.
