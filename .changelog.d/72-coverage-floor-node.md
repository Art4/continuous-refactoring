New `coverage-floor` tooling-tree node (PHPUnit child, Signal-producing — no `structural-scan` gating): measures test coverage against a self-tightening ratchet committed to the target repo (`.coverage-floor`, only ever rises via a normal reviewed commit, never auto-bumped by CI) instead of a fixed percentage, and feeds the existing "Untested / hard-to-test" candidate-selection cue with real per-file Clover-XML numbers. Driver-agnostic — PCOV is the adoption default, Xdebug works too.
