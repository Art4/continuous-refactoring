`psr-4`'s autoloader-wiring check now reports exactly which entry points still need `vendor/autoload.php` wiring (`details.unwired_entry_points`) instead of only a boolean — a tooling-tree node's own generated CI-helper script (e.g. `coverage-floor`'s `scripts/check-coverage-floor.php`) can structurally never need it, and telling that apart from genuine unaddressed application work is now a documented judgement call for the agent reading the result (`psr-4.md`), not a guess the parser itself makes.
