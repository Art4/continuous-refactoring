# Continuous Refactoring

The vocabulary of a portable agent-skill suite that keeps a software project under continuous refactoring — repeated runs that find, plan, execute and verify structural improvements, with all state kept in the project's issue tracker and forge.

## Language

The suite's terms live in the skills, so that an agent working in a target has them too:
[`skills/continuous-refactoring-run/references/glossary.md`](skills/continuous-refactoring-run/references/glossary.md).
A new or changed term goes there.
